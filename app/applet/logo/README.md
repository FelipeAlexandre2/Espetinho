# 🖼️ Logo & Capa Oficial do Sistema (Maresia)

Esta pasta é o local exclusivo onde a logo e capa do sistema ficam cadastradas no GitHub.

### 📌 Como funciona:
- O sistema carrega a imagem **diretamente deste arquivo** (`logo.png` / `capa.png`).
- **Ninguém consegue mudar pela tela do sistema** (todos os botões e opções de troca foram removidos da interface para evitar bagunça).
- Somente você, pelo repositório do GitHub, tem o controle de colocar ou atualizar a logo e capa do sistema.

### 📁 Arquivos oficiais:
- **`logo.png`** (ou **`capa.png`**): Imagem oficial em alta resolução.
- **`logo.jpg`** (ou **`capa.jpg`**): Versão JPG compacta.
- **`logo.svg`**: Vetor de backup.
- Caminhos: `logo/logo.png`, `logo/capa.png`, `public/logo/logo.png`.
