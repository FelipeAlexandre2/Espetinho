# 📸 Pasta para Fotos do Sistema (Maresia)

Coloque aqui no GitHub as fotos do sistema, fotos dos pratos, banners e fotos do estabelecimento do cliente.

### Como usar:
- Adicione as fotos desejadas nesta pasta (ex: `foto-sistema.png`, `fachada.jpg`, `pratos.png`)
- Os arquivos ficam também acessíveis via `public/fotos-sistema/`
