# Pasta para Fotos do Sistema - Maresia

Guarde aqui todas as fotos do sistema, fotos dos pratos, banners e fotos do estabelecimento do cliente.

### Como usar:
- Coloque suas fotos aqui (ex: `foto-sistema.png`, `cardapio-banner.jpg`, `fachada.jpg`, etc.)
- Para referenciar qualquer imagem colocada aqui no sistema, o caminho público será:
  `/fotos-sistema/nome-do-arquivo.png`

Exemplo:
`public/fotos-sistema/banner.png` fica disponível em `/fotos-sistema/banner.png`.
